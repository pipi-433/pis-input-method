# pis'input method 2.0.0

2026-10-10，版本 2.0.0。

本文件记录已经生成的 2.0.0 ARM64 APK。之后源码新增的[候选栏横向滑动](pis-horizontal-candidates.md)尚未打入该 APK，也未进入此前源码 ZIP；最新源码状态见 [实现状态](../../PIS_MIGRATION_STATUS.md)。本页版本号、大小、签名和校验值仍对应原发行文件。

## 版本与安装

- 应用名：`pis'input method`。
- 包名：`io.pis.inputmethod`，ARM64 versionCode `20002`，Android 8.0 及以上。
- 专用 pis Release 签名；关闭调试标记，启用 R8 代码/资源裁剪。
- 与 `io.pis.inputmethod.debug` 测试版并存，首次安装重新启用并选择输入法。设置、个人词频和语音热词不从测试版自动迁入；旧版个人词卡不迁入。
- 后续正式版在包名、签名不变且 versionCode 增大时覆盖更新。

## 保留的功能

- 中文默认启动，全拼和双拼（首道），统一字母高度与双拼声韵母小标，中英切换；纯数字九宫格。
- 顶部候选和英文提示、gloss.db 长按中英释义、长按句号整句离线翻译；拼音 composing 写进当前应用输入框。
- 空格长按离线语音、标点/热词/候选修正、语音完成后可局部编辑；逗号长按剪贴板。
- 精简设置：主题、自定义颜色、高度、底部上移、按键音、震动和必要输入/语音选项，以及个人词频管理。
- 苹果冷灰键帽、微玻璃圆角输出栏、右侧 24 灯动画/状态灯；点阵点击展开候选，无组合输入时收起键盘。
- 最新跟手改动：多指下一键按下时结算前普通键，删除按下即首次删除；长按、滑动及功能键保持独立处理；候选差量刷新和译文宽度预留。
- 模型后台预热。系统回收进程后重新加载。

## 发行清理

- 输入验证 Activity 及探针移入 debug 源集；正式设置页移除试输入区。
- 系统设置入口统一精简设置页，并展示版本与资源来源。
- 当前词义使用gloss.db，正式包不再携带未使用的 WordNet 数据库；调试版保留实验资源。
- 保留输入引擎数据、翻译/语音模型与版权说明。
- 签名文件和本机加密凭据不进入交付目录与 Git；签名公钥指纹、APK 哈希由包检查报告记录。
