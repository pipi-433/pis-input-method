# pis' input method 2.0.3

2026-10-12。Android 8.0 及以上，ARM64，包名 `io.pis.inputmethod`，versionCode `20032`，沿用原 Release 签名，可覆盖升级 2.0.2。本轮提供一个正式 ARM64 APK，构建与包校验通过。

发行文件与校验资料见 [v2.0.3 Release](https://github.com/pipi-433/pis-input-method/releases/tag/v2.0.3)。文件名为 `pis-input-method-2.0.3-arm64.apk`，最终大小和 SHA256 见 Release 附件 `package-audit.json` 与 `SHA256SUMS.txt`。

## 新功能与操作

- 在顶部候选上向上滑动，输入首条本地英文，例如“技术 → technology”“基数 → cardinal number”。无英文映射时不提交文本、不选中中文候选；编辑器拒绝写入时保留候选。
- 点击选词、左右浏览和长按词义保留。上滑从按下时捕获候选与输入状态，完成时核对当前会话。
- 长按词义弹窗采用当前键盘主题的半透明渐变与玻璃边缘，支持浅/深色及横屏；API 31 及以上在系统支持时启用原生背景模糊，模糊不可用时调整面板背景。
- 保留动态候选宽度、准确首道双拼编码和字母上滑/长按快捷输入。

操作与调试预览截图见 [候选英文与玻璃词义弹窗](../features/pis-candidate-english-and-glass.md)。旧 [v2.0.2 APK](pis-2.0.2.md)不包含本轮英文上滑与玻璃词义弹窗，历史文件及校验值保留。

## 验证

功能代码已通过 Kotlin 编译与 11 项单元测试（46 秒），包含英文映射、手势判断、编辑器接受/拒绝写入时序和异常结束批次检查。

模拟器实际触摸事件、4 组英文词典映射、真实 Fcitx 候选分页及 12 组零声母编码检查通过。API 35 实际弹窗/键盘预览检查覆盖浅/深色、横屏、长释义、加载/空状态及原生模糊切换。

本轮 ARM64 Release 构建成功（3 分 15 秒），52 个接口方法检查、原 Release 证书、v2 签名、模型/词典哈希和 16KB ELF/ZIP 对齐检查通过；无调试组件、无 INTERNET 权限。

上述运行验证范围为候选视图事件、词典/引擎和弹窗预览；vivo 真机尚未验证。
