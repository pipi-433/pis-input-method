# pis' input method 2.0.1

2026-10-10。Android 8.0 及以上，ARM64，包名 `io.pis.inputmethod`，versionCode `20012`，沿用原 Release 签名，可覆盖升级 2.0.0。

[下载 APK 与校验文件](https://github.com/pipi-433/pis-input-method/releases/tag/v2.0.1)。离线模型随包提供，安装包约 1.32 GB。

## 修复与操作

- 修复候选分页崩溃：新接口访问器由代理显式实现；正式打包完整编译 Kotlin，并核对编译后的 52 个接口方法。
- 首道双拼使用准确编码，关闭相邻键错按纠正。`UI` 返回“诶、欸、誒”，`UF` 返回“鞥”；全拼保留 QWERTY 纠正。
- 26 个字母键上滑或长按输入角标数字、符号；数字符号内容保持原布局，删除键左右扫操作保留。
- 设置页补充零声母编码和上滑快捷输入提示。

## 首道零声母编码

| 音节 | 编码 | 音节 | 编码 |
|---|---|---|---|
| a | AA | ai | AI |
| an | AN | ang | AY |
| ao | AO | e | UE |
| ei | UI | en | EN |
| eng | UF | er | ER |
| o | OO | ou | OU |

上述为完整零声母音节；带声母时 `M` 对应韵母 `ei`，`V` 对应韵母 `ui`，例如 `BM → bei`、`GV → gui`。

## 验证

- 7 项单元测试通过，覆盖主题/转义、接口代理和全部 26 个字母快捷输入定义。
- x86_64 模拟器实际 Fcitx 引擎验证候选分页、12 组零声母编码、`BM`、`GV` 和 `NIHD → 你好`。
- 26 个实际键视图的事件回归通过：上滑提交一次角标字符，下滑不提交角标字符，长按提交原角标字符。
- ARM64 Release 完成编译、52 方法检查、签名、模型/词典哈希与 16KB ELF/ZIP 对齐检查。具体文件大小和 SHA256 附在 Release 的 `package-audit.json`、`SHA256SUMS.txt`。

vivo 真机交互验证由设备上的升级安装继续完成。
