# 苹果冷灰与玻璃边缘

2026-10-09。苹果冷灰配色与玻璃边缘的原生 Android 实现记录。

## 确认值与实现

- 键盘底 #D5D8DE，键帽 #F7F8FA，功能键 #BFC4CD，顶部 #E9EBEF，文字 #1C1C1E，次要字 #727780，阴影 #B1B6C0。
- 新默认主题 palette_revision=4。已知旧默认灰色主题自动升级；自定义、深色、雾蓝主题保留。
- `PisKeycapDrawable` 使用白色上沿、冷灰白中部和略深冷灰下沿；功能键从提亮灰渐变至自身底色。保留旧文字 padding 和触摸范围，默认圆角从 4dp 微调到 5dp。
- 输出栏保持 56dp 高、右侧 68dp 点阵模块、12dp 圆弧。新增 `PisGlassBarDrawable`，作为整个输出栏的 foreground，绘制薄玻璃斜向边缘、细上沿高光、淡下沿阴影。所有内容共用同一底色，中间不做模糊或透明处理。
- 键盘外层按上方 12dp、下方 16dp 裁剪圆弧，避免截断顶部玻璃边缘。候选展开、整句译文和语音栏仍在同一容器内。
- 点阵亮度是上一版再提高 50%：渲染曲线系数从 1.2 改为 1.8，达到暖白上限后截断，反馈按实际事件状态显示。
- 对照演示移植暖白径向光晕，alpha 系数从 90 改为 135，24 个 shader 在尺寸变化时缓存；画帧时不创建新的 shader。未亮点和灯窗改为演示的冷灰 #B0B6BF / #D1D4DA，三灯红黄绿 #FF5F57 / #FEBC2E / #28C840。

## 保留功能

默认启动中文；长按候选仅使用`gloss.db` 的中文/英文/音标/词性，不追加 WordNet 或模型补译。逗号长按剪贴板、空格长按语音、句号长按整句英译，点阵点击展开/收起候选及闲置隐藏键盘，全部保留。

## 边缘补强实验

此阶段将单一细高光扩展为 2.6dp 折射带、亮外沿、内侧反光和下沿阴影。边框之外保持统一灰色，候选/翻译位置与栏高保持；裁剪圆角为 12dp。

三灯新增 `lampVisualGain=3`：彩色径向光晕强度乘三，反光 alpha 80→240，激活脉冲提亮系数 .14→.42。发光范围 6.5dp，灯面半径 3.2dp，保留原色相。24 灯使用 1.8 渲染曲线；径向 shader 在尺寸变化时缓存。

开发版 `pis-v2-glass-bright` 已通过 assembleDebug（39 秒）并安装到模拟器。验证范围为构建与安装。
## 最终微玻璃与状态点亮

最终玻璃边缘采用 0.6dp 低透明边缘和轻微下沿，中部保持统一底色。亮度增强仅在点亮状态生效。

红黄绿三灯去掉外扩彩色光晕、白色描边、大白芯和增大尺寸，恢复 2.6dp 半径及小反光。只有当前对应灯在真实活动帧中使用三倍脉冲系数和较亮的小反光；待机/其他灯保持原常驻外观，淡回待机时不再重放亮度脉冲。

24 灯珠的待机中央四点 level 恢复 .25，静止/停留帧使用低亮曲线 .85，无外部光晕；输入或真实任务活动帧才使用已确认的 1.8 曲线与暖白动效。系统禁用动画时真实任务仍可显示静态活动状态，普通按键不制造持续亮光。

开发版 `pis-v2-feedback-subtle` 已通过 assembleDebug（38 秒）并安装到模拟器。验证范围为构建与安装，完整回归测试待完成。
